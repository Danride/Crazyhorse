# Crazyhorse / KING’S ROAD

Средневековый бесконечный раннер от первого лица. Версия игры 2.1.0.

## Статус

Репозиторий подготовлен к импорту проекта. Полный архив раздельных исходников и игровых данных подготовлен отдельно; пока в репозиторий загружено только это описание. Распакуйте ZIP и загрузите содержимое папки Crazyhorse в корень репозитория, заменив README при необходимости.

## Структура проекта

- `index.html` — точка входа
- `src/core/` — состояние, жизненный цикл, сохранения
- `src/engine/` — WebGL и геометрия
- `src/world/` — биомы, здания, растительность, чанки, погода и события
- `src/npc/` — Utility AI, память, эмоции, трафик и диалоги
- `src/physics/` — столкновения и отскоки
- `src/gameplay/` — игровой цикл и монеты
- `src/render/` — модели, облака, эффекты и превью
- `src/input/` — клавиатура и сенсорное управление
- `src/audio/` — звуки
- `src/ui/` — интерфейс и меню
- `assets/` — игровые данные моделей, анимаций и текстур
- `styles/` — CSS
- `tools/` — сборка и тестирование

После импорта: откройте `index.html` или запустите `python -m http.server 8000`. `npm test` проверяет синтаксис и игровую логику с заглушками WebGL. `npm run build` собирает автономный HTML в `dist/`.

Первый этап рефакторинга сохраняет общий контекст скриптов и исходную механику. Перед публикацией сторонних ассетов проверьте разрешение на распространение моделей и текстур.
